# Shop SMart

Exploit the vulnerabilities in the S-Mart storefront to recover four hidden tokens.

**NICE Work Roles**

- [Exploitation Analysis](https://niccs.cisa.gov/tools/nice-framework/)

**NICE Tasks**

- [T1359](https://niccs.cisa.gov/tools/nice-framework/): Perform penetration testing

## Background

S-Mart is a recently launched e-commerce platform selling a wide range of household goods. A routine security assessment has flagged the application as potentially vulnerable to several of the OWASP Top Ten web application risks.

Your mission: exploit the vulnerabilities in the S-Mart storefront to recover four hidden tokens.

## Getting Started

Browse to the S-Mart storefront at `http://shop-smart` to begin your assessment.

Knowledge of the [OWASP Top Ten](https://owasp.org/www-project-top-ten/) will be useful for this challenge.

## Tokens

- Token 1: Log in as an administrator user
- Token 2: Access bcampbell's order history
- Token 3: Retrieve the token3.txt file from the /var/www/ directory
- Token 4: Check out with the hidden chainsaw product
